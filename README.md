# 🛒 Amazon Product Data Analysis & Interactive Dashboard


## 📌 Project Overview
This project delivers an end-to-end data analysis solution on an extensive dataset of over **100,000+ Amazon products**. The goal was to clean raw, unstructured e-commerce data, perform exploratory data analysis (EDA), and extract actionable business insights regarding product pricing, customer ratings, category trends, and revenue drivers.

---

## 🛠️ Tech Stack & Tools
* **Data Cleaning & Transformation:** Excel / SQL
* **Exploratory Data Analysis:** SQL / Excel
* **Data Visualization:** Power BI
* **Version Control:** Git & GitHub

---

## 📊 Key Insights Uncovered
* **Top Performing Categories:** Identified the top 5 product categories driving the highest volume and average ratings.
* **Pricing vs. Demand Trends:** Uncovered optimal price points that correlate with higher customer engagement and review density.
* **Data Integrity:** Cleaned missing attributes across 100k+ records, resolving duplicate entries and inconsistent category naming conventions.

---

## 🗂️ Data Pipeline & Process
1. **Data Ingestion & Cleaning:**
   * Handled null values, standardized currency formats, and removed redundant records.
   * Optimized data types to handle large-scale dataset performance efficiently.
2. **Exploratory Data Analysis (EDA):**
   * Queried key metrics using SQL (aggregations, GROUP BY, window functions).
3. **Interactive Dashboard Build:**
   * Constructed dynamic visual components in Power BI to allow filtering by category, price tier, and rating ranges.
